# 第四阶段开发计划：内容发现与协作体验

更新时间：2026-08-11

## 阶段目标

前三个阶段已经完成文章持久化、互动通知、个人知识库和管理治理。第四阶段把重点从“能力已经存在”转向“员工日常真正好用”：让首页展示真实内容，让文章讨论形成闭环，并提供按分类、标签和主题持续发现知识的入口。

## 开发顺序

### 1. 员工文章评论区

- 在文章详情页展示根评论与一层回复。
- 支持发表评论、回复、编辑自己的评论和软删除。
- 对管理员隐藏、用户删除的内容提供清晰占位，不泄露原文。
- 切换当前模拟用户或文章时自动刷新评论。

### 2. 动态知识首页

- 后端提供当前用户可见的最新文章、热门文章和订阅更新聚合接口。
- 首页从静态示例切换为真实 PostgreSQL 数据，并提供加载、空状态和失败重试。
- 文章卡片展示作者、分类、标签、发布时间及互动摘要。

### 3. 分类与标签发现

- 提供分类、标签详情和对应文章列表。
- 串联搜索、订阅和文章详情入口。
- 保证停用目录项不再进入新的内容关联，但历史内容仍可解释。

### 4. 专题与知识集合

- 支持员工把多篇文章整理为有顺序的专题集合。
- 提供专题详情、维护入口和权限校验。
- 与个人知识库、首页推荐位衔接。

### 5. 质量与运营收尾

- 补齐核心接口与前端状态测试、全量回归和阶段验收记录。
- 增加首页与协作数据的管理概览，为后续推荐策略提供基线。
- 整理本地启动与验收说明；Docker、Nginx 和正式部署继续暂缓。

## 提交与分支约定

- 日常开发继续使用 `codex/develop`。
- 每完成一个大功能或模块，使用中文规范提交信息独立提交并推送。
- 阶段完成后通过 Pull Request 合并到 `main`，不直接在 `main` 开发。

## 本阶段验收标准

- 员工能够围绕已发布且有权阅读的文章完成评论与回复闭环。
- 首页不再依赖写死的文章或数量，所有内容都来自真实接口。
- 分类、标签、搜索、订阅、专题和文章详情之间可以连续导航。
- Java 17 后端测试以及两个前端项目的测试、类型检查和生产构建全部通过。
- 不要求 Docker、Nginx 或生产环境部署。
