# 分类与标签文章发现 API

## 查询目标下的文章

`GET /api/articles/discovery?type=CATEGORY&targetId=engineering&limit=30`

| 参数 | 说明 |
| --- | --- |
| `type` | `CATEGORY` 或 `TAG`，大小写不敏感 |
| `targetId` | 分类或标签 ID，只接受小写字母、数字和连字符 |
| `limit` | 最多返回数量，默认 30，最大 50 |

响应返回目标类型、目标 ID、生成时间，以及按最近发布时间倒序排列的文章。文章卡片字段与动态首页一致，包含摘要、分类、标签和互动数量。

## 权限与目录状态

- 只查询 `PUBLISHED` 状态文章，并逐篇执行统一阅读权限校验；
- 当前员工不在文章部门或团队可见范围时，该文章不会出现在结果中；
- 员工端目录只展示启用中的分类和标签；
- 分类或标签停用后不能再关联到新文章，但已有文章仍可通过历史链接和目标 ID 查询，避免历史内容失去解释信息；
- 统计服务不可用时文章仍正常返回，互动数量降级为 0；权限服务异常时不放宽权限。
