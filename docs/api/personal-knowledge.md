# 个人知识库接口

个人知识库直接读取互动事实，当前提供收藏和最近浏览两个列表：

```http
GET /api/me/knowledge/favorites?limit=50
GET /api/me/knowledge/recent-views?limit=50
```

服务只接受 Gateway 注入的 `X-User-Id`，不允许客户端查询其他员工的历史。`limit` 范围为 1～100。

响应包含文章 ID、互动类型和首次产生该互动的时间。接口不会返回文章正文；前端获取文章详情时必须继续
调用文章服务，由文章服务根据当前身份与组织范围实时校验可见权限。因此文章后来被撤回、删除或调整可见范围时，
历史互动不会成为绕过权限的入口。
