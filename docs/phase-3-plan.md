# 第三阶段开发计划

更新时间：2026-08-01

## 阶段目标

第二阶段已经补齐互动、通知、审计和管理数据面板。第三阶段围绕“个人知识工作台与持续治理”展开，
让员工能长期整理和追踪知识，让管理员能处理内容社区规模扩大后的治理问题。

## 实施顺序

1. **个人知识库**
   - 提供当前员工的收藏文章列表；
   - 提供最近浏览历史；
   - 历史接口只返回互动事实，文章详情仍由文章服务实时校验可见权限。
2. **分类与标签订阅**
   - 员工可订阅和取消订阅分类、标签；
   - 文章发布后向匹配订阅者生成站内通知；
   - 使用 PostgreSQL 和 Outbox，保证订阅关系和通知可恢复。
3. **评论治理**
   - 管理端按文章、作者和状态查询评论；
   - 支持管理员隐藏和恢复违规评论；
   - 治理动作写入关键操作审计。
4. **个人与治理体验收尾**
   - 管理端增加订阅覆盖和评论治理概览；
   - 员工端整合个人知识库、订阅与通知入口；
   - 完成权限、幂等和全量回归。

## 当前约束

- 继续使用 Java 17、Spring Boot 3.3 和 PostgreSQL；
- 暂不依赖 Docker、Nginx、Kafka 或 RabbitMQ；
- Redis、Elasticsearch、MinIO 的部署联调继续暂缓；
- 每个独立大模块使用中文规范提交信息提交到 `codex/develop`；
- GitHub 网络不可用时先保留本地提交，恢复后统一推送。
