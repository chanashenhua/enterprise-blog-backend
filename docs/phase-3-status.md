## 已完成功能

### 1. 个人知识库

- 员工可查看自己的收藏文章和最近浏览；
- 历史接口仅返回互动事实，前端逐篇请求文章详情并重新校验当前可见权限；
- 支持从知识库取消收藏，切换演示身份后自动刷新；
- 知识库页面串联主题订阅和通知中心入口。

### 2. 分类与标签订阅

- 员工可查询、订阅和取消订阅启用中的分类与标签；
- 订阅关系受数据库唯一约束保护，重复请求保持幂等；
- 全公司文章发布时通过独立 PostgreSQL Outbox 通知匹配订阅者；
- 同一员工同时命中分类和多个标签时只生成一条通知，文章作者不会收到自己的通知；
- 部门和团队文章不发送订阅通知，避免标题泄露给没有权限的订阅者；
- 管理端展示订阅关系、覆盖员工、目标类型和热门主题聚合数据。

### 3. 评论治理

- 管理员可按文章、作者和 `ACTIVE`、`HIDDEN`、`DELETED` 状态筛选评论；
- 支持隐藏与恢复，隐藏时保留正文以便复核，员工端不返回隐藏正文；
- 用户已删除的评论不能恢复，重复隐藏和恢复按幂等成功处理；
- 评论状态变更与审计 Outbox 在同一事务中写入；
- 管理端展示全局评论状态、涉及文章和作者数量。

## 本地 PostgreSQL 验收数据

- 订阅关系 3 条，覆盖 2 名员工：2 条标签订阅、1 条分类订阅；
- 评论 3 条：2 条正常、1 条隐藏，涉及 1 篇文章和 2 名作者；
- 演示数据包含订阅文章通知和评论隐藏审计记录；
- 所有新增种子写入均可重复执行。

## 权限与可靠性验收

- 所有员工接口均从网关注入的用户上下文读取当前用户，不接收请求体中的任意用户 ID；
- 订阅和评论治理概览仅允许 `ADMIN` 角色访问；
- 个人历史记录不能绕过文章服务的实时可见权限；
- 发布通知以 `Outbox 事件 ID + 接收员工 ID` 作为幂等键；
- 评论隐藏和恢复动作最终写入统一操作审计服务；
- `.idea/`、数据库密码、构建产物和本机配置没有加入前端提交。

- 部门和团队文章的订阅通知，需要在未来接入组织成员匹配后再开放；
