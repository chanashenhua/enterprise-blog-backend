# 第二阶段完成状态

更新时间：2026-08-01

## 结论

第二阶段开发功能已全部完成，当前不包含 Docker、Nginx、生产部署和完整环境部署验收。

## 已完成功能

### 文章互动统计

- 已认证员工访问文章时记录去重浏览；
- 支持点赞、取消点赞、收藏和取消收藏；
- 文章详情返回互动总数和当前员工状态；
- 互动前继续调用文章服务校验可读权限；
- 管理端提供全站汇总、参与人数、活跃文章数和热门文章排行。

### 站内通知

- 审核通过、审核驳回和评论回复生成站内通知；
- 上游通过本地 Outbox 异步投递，通知服务按事件标识去重；
- 员工支持通知列表、未读数量、单条已读和全部已读；
- 管理端支持通知总量、已读/未读、覆盖人数、类型分布和条件查询；
- 管理员查询不允许代替员工修改已读状态。

### 关键操作审计

- 新增独立 `audit-service`，默认端口为 `8092`；
- 审核决策、分类维护和标签维护写入审计事件；
- 审核服务与标签服务通过本地 Outbox 可靠投递；
- 审计服务按事件标识幂等落库；
- 管理端支持按操作人、动作、资源和时间范围查询。

### 管理端增强

- 新增文章互动概览页面；
- 新增站内通知治理页面；
- 新增关键操作审计页面；
- 工作台和侧边导航已接入以上入口，并保留审核、索引任务、分类标签管理功能。

## 启动补充

使用 IDEA 本地运行时，除原有服务外还需重新导入 Maven，并启动
`com.company.blog.audit.AuditServiceApplication`。互动概览依赖 `stats-service`，通知治理依赖
`notification-service`，所有管理端请求仍统一经过 Gateway。
