# 登录与权限收尾记录

- 三账号会话请求绑定会话代次；退出立即取消请求，旧响应不得更新当前页面或清除新会话。
- 401 每个会话只失效一次；403 保留身份。移除业务页对模拟账号切换的监听。
- 登录回跳拒绝编码外链、反斜线、控制字符及登录路由循环。
- 员工端读者不显示文章创作入口，直达创作路由显示权限提示。
- POST /api/articles/drafts 在服务端要求 AUTHOR 或 ADMIN；未认证返回 401，读者返回 403。
- 专题仍遵循原规则：员工均可整理自己的知识集合，维护权限由所有权控制。
- OIDC 保留适配契约，当前阶段只运行本地演示。

验证：Java 17 全量 Maven 回归 153 项通过；员工端 Vitest 45 项、管理端 37 项通过；两个生产构建通过。
浏览器边界测试 7 项通过，业务 API 使用测试桩，覆盖三账号刷新/退出、读者直达拦截、非管理员不发起管理接口和 1440/390px 登录页。
真实后端角色校验由 MockMvc 测试覆盖；本次没有启动完整后端服务或验证 Elasticsearch/MinIO。
