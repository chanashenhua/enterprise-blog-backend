# 第二阶段开发计划

更新时间：2026-08-01

## 阶段目标

第一阶段已经完成文章发布主链路和基础治理能力。第二阶段围绕“知识被使用之后发生什么”继续建设，
让员工能够互动、接收反馈，让管理员能够追踪关键操作。

## 实施顺序

1. **文章互动统计**
   - 记录已认证用户对文章的去重浏览。
   - 支持点赞、取消点赞、收藏和取消收藏。
   - 返回文章的浏览、点赞、收藏数量，以及当前用户的互动状态。
   - 所有互动前仍由文章服务校验可读权限，统计服务不能绕过文章可见范围。
2. **站内通知**
   - 发布、审核结果、评论回复等事件生成站内通知。
   - 支持未读数量、通知列表与已读状态。
3. **关键操作审计**
   - 记录内容治理和管理端关键动作。
   - 提供按操作者、资源和时间范围查询的管理端入口。
4. **管理端增强**
   - 增加互动概览、通知治理和审计查询页面。

## 当前约束

- 本阶段继续使用 PostgreSQL 作为持久化真相来源。
- 暂不引入 RabbitMQ 或 Kafka，跨服务异步能力继续沿用 Outbox 思路。
- Docker、部署和生产环境联调仍按当前约定暂缓。
- 每完成一个独立大模块，使用中文规范提交信息提交到 `codex/develop`。
